# TopicTurn

TopicTurn is a reusable, browser-based tool for interactive speaking sessions, workshops, training events, and Toastmasters Table Topics.

## Live site

[Open TopicTurn](https://hassambashir.github.io/TopicTurn/)

## Features

- Configure the number of rows and seats in a room
- Disable seats that are empty or ineligible
- Randomly select a participant with an animated seating map
- Randomly select topics without repeating them
- Add, edit, or import a custom topic list
- Change the organisation, session type, and session title
- Use a responsive presentation view and full-screen mode
- Preserve the current session locally in the browser

## Use

1. Open the live site.
2. Enter the session details.
3. Set the room dimensions and generate the seating map.
4. Add or import the topic list.
5. Select **Start session**.
6. Generate a topic and select a participant in either order.

## Run locally

Download `index.html` and open it in a modern browser. TopicTurn is a static application with no server, installation, account, or API key required.

## Privacy

Session settings are stored only in the browser using local storage. TopicTurn does not send session data to a backend.
